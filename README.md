# Undergraduate Coursework

Projects from my B.S. in Management Information Systems at California State University, San Marcos (2020). These are early programming and database exercises, kept here as a record of where I started.

For my current analytics work, see [data-analytics-portfolio](https://github.com/JamesAPease/data-analytics-portfolio).

## Java Programming

Introductory Java exercises covering input handling, control flow, and object-oriented basics.

| Project | What it does | Concepts |
| --- | --- | --- |
| `BMI_Calculator` | Calculates body mass index from user-entered height and weight | User input, arithmetic |
| `Calories_Exercise` | Estimates calories burned across activities using MET values | Variables, formulas |
| `Pig_Latin` | Converts a first and last name into Pig Latin | String manipulation |
| `Practice_With_Scanners` | Chapter exercises, including the Babylonian square-root method | Loops, Scanner input |
| `Simple_Kuman_Math` | Quizzes the user on random addition problems until they quit | Random numbers, while loops |
| `Simple_Bank_Account` | Bank account with deposits and withdrawals | Classes, encapsulation |
| `Casino_Membership` | Casino loyalty membership that tracks reward points | Classes, constructors, methods |

## Database Design (MIS 411 Team Project)

A team project to design and deploy a relational database in the cloud, with teammates Jason Rivkin, Ashley Brown, Michael Carter, and Matthew Lam.

- **Implementation:** set up database and application virtual machines, installed MariaDB, and created tables with data types, primary keys, and foreign keys
- **Operations:** ran queries and database operations against the deployed system

Write-ups for both phases are included as Word documents.
